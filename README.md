# Brijesha Vora — Portfolio

Plain HTML, CSS and vanilla JavaScript, no build step, hosted on GitHub Pages.

## Files
| File | Purpose |
|---|---|
| `index.html` / `style.css` / `script.js` | The site |
| `config.js` | **Analytics switch** — put your GoatCounter code here |
| `Brijesha_Vora_Resume.pdf` | Résumé (generated by `tools/build_resume.py`) |
| `assets/resume-preview.png` | Résumé preview image on the site |
| `assets/apps/<slug>/` | Real app screenshots for each Play Store app |
| `tools/build_resume.py` | Rebuilds the résumé PDF |
| `resume-archive/` | Your previous résumé, kept for reference |
| `favicon.svg` / `favicon.png` / `apple-touch-icon.png` | Site icon (capital B) |
| `profile.webp` / `profile.jpg` | Optimised portrait (`profile.png` is the original, no longer loaded) |

## Run locally
    python3 -m http.server 8000      # then open http://localhost:8000
(Analytics never fires on localhost or file://.)

## Add your real app screenshots
Slugs: `field-engineer`, `self-care`, `wellness-rituals-sales`, `revolv-store-ordering`, `revolv-logistics`
Save 3–5 original Play Store screenshots per app in `assets/apps/<slug>/` named `screen-1.png`, `screen-2.png` … `screen-5.png` (`.jpg` / `.webp` also work; numbering must be consecutive). They appear unchanged inside phone frames in a swipeable gallery (arrows, dots, touch swipe). With none, the card shows a neutral tile. Nothing is faked.

## Analytics (GoatCounter — no cookies, no personal data)
1. Sign up free at https://www.goatcounter.com and choose a site code, e.g. `brijesha`.
2. Put it in `config.js`: `goatcounter: 'brijesha'`.
3. In GoatCounter: Settings → Site → tick **Allow adding visitor counts on your website** (needed for the footer counter; set `showPublicCounter:false` to keep numbers private).
4. Commit and push. Your dashboard shows total pageviews, unique visitors and visits over time; the site footer shows page views and unique visitors once real data exists.

## Update the résumé
Edit the CONTENT section of `tools/build_resume.py`, then `python3 tools/build_resume.py Brijesha_Vora_Resume.pdf` (needs `pip install reportlab`). Regenerate the preview with `pdftoppm -r 100 -png -singlefile Brijesha_Vora_Resume.pdf assets/resume-preview`.

## Deploy
    git add -A && git commit -m "Portfolio upgrade" && git push origin main
