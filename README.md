# Brijesha Vora — Portfolio

Personal portfolio for Brijesha Vora, Software Engineer (Flutter · Java · Spring Boot · MySQL). Plain HTML, CSS and vanilla JavaScript, with no build step. It loads the Fraunces and DM Sans fonts from Google Fonts and falls back to system fonts if they are unavailable.

## Files (all in the repository root)
index.html · style.css · script.js · README.md · profile.png · Brijesha_Vora_Resume.pdf

## Run locally
Open `index.html` in a browser.

## Deploy
Push these files to the root of the `brijesha135.github.io` repository (branch `main`).

## Editing
- Replace `profile.png` or `Brijesha_Vora_Resume.pdf` with the same filename to update them.
- Colours and fonts are CSS variables at the top of `style.css`; page copy is in `index.html`.
